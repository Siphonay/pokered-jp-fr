# Pokémon Version Bleue JP-FR

Ce dépôt est le code source d’une modification de Pokémon Version Bleue basée sur son [désassemblage](https://github.com/einstein95/pokered-fr) par *einstein95*.

**Téléchargez les patches [ici](https://github.com/Siphonay/pokered-jp-fr/releases).**

Cette modification restaure de manière authentique le contenu de la version Bleue japonaise, qui a servi de base aux adaptations internationales de Rouge et Bleue, mais qui comporte quelques changements exclusifs.

Sont restaurés :
- Les Pokémon disponibles dans la nature, certains étant exclusifs à cette version
- Les Pokémon disponible en échange auprès de PNJ ou à l’achat comme prix du Casino Rocket
- Quelques autres changements mineurs, consultez la liste exhaustive des changements [ici](https://github.com/Siphonay/pokered-jp-fr/wiki/Liste-des-changements), ou découvrez-les par vous-même !

Consultez aussi la branche [main](https://github.com/Siphonay/pokered-jp-fr/tree/blue) pour une version JP-FR basée sur le contenu des versions Rouge et Verte japonaises, qui sont plus nombreuses.

Cette modification ne comporte pas de changements "quality of life", ni d’autre contenu original qui ne serait pas basé sur les sorties officielles.

Vous pouvez échanger et combattre avec les versions JP-FR entre elles, ainsi qu’avec les versions originales des jeux de la première génération. Elles sont aussi compatibles avec la capsule temporelle des jeux de la seconde génération.

## Assemblage

Le code dans ce dépôt assemble la ROM suivante :

- Pokémon Version Bleue JP-FR `sha1: 38d91cb75fd8ec2746a2929ce937869095216f7f`

Pour plus d’informations, consultez [cette page](https://github.com/pret/pokered/blob/master/INSTALL.md).
