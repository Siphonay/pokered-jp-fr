# Pokémon Version Rouge et Verte JP-FR

Ce dépôt est le code source d’une modification de Pokémon Version Rouge et Bleue basée sur leur [désassemblage](https://github.com/einstein95/pokered-fr) par [einstein95](https://github.com/einstein95).

**Téléchargez les patches [ici](https://github.com/Siphonay/pokered-jp-fr/releases).**

Cette modification restaure de manière authentique le contenu des versions Rouge et Verte japonaises ayant été changé dans les adaptations françaises Rouge et Bleue, comme si ces jeux provenaient d’un univers parallèle où ils étaient sortis simultanément en japonais et en français.

Sont restaurés :
- Les graphismes originaux, y compris les sprites des 151 Pokémon du jeu
- Les descriptions du Pokédex sont adaptées de celles de Pokémon Rouge Feu, ces dernières ayant été traduites depuis les descriptions originales dans les versions Rouge/Verte japonaises
- La Grotte Inconnue dans sa disposition originale
- Bien plus encore, consultez la liste exhaustive des changements [ici](https://github.com/Siphonay/pokered-jp-fr/wiki/Liste-des-changements), ou découvrez-les par vous-même !

Consultez aussi la branche [blue](https://github.com/Siphonay/pokered-jp-fr/tree/blue) pour une version JP-FR basée sur le contenu de la version Bleue japonaise, plus proche des versions Rouge/Bleue françaises, mais avec quelques différences exclusives.

Cette modification ne comporte pas de changements "quality of life", ni d’autre contenu original qui ne serait pas basé sur les sorties officielles.

Vous pouvez échanger et combattre avec les versions JP-FR entre elles, ainsi qu’avec les versions originales des jeux de la première génération. Elles sont aussi compatibles avec la capsule temporelle des jeux de la seconde génération.

## Assemblage

Le code dans ce dépôt assemble les ROMs suivantes :

- Pokémon Version Rouge JP-FR `sha1: 7041ec96823059c76126a5bbfe5a2215a32a0d26`
- Pokémon Version Verte JP-FR `sha1: 7ca1e67e103db05cd74652abd38b53f77e3290a5`

Pour plus d’informations, consultez [cette page](https://github.com/pret/pokered/blob/master/INSTALL.md).
